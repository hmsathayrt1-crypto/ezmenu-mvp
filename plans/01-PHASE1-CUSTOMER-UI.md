# Phase 1 — المشروع الأساسي + واجهة الزبون الثابتة

## 🎯 الهدف
إعداد مشروع React + Vite + Tailwind + TypeScript وبناء واجهة القائمة للزبون ببيانات ثابتة (mock data).

## ✅ المهام

### Task 1.1: إعداد المشروع
- [ ] إنشاء مشروع Vite + React + TypeScript
- [ ] تثبيت Tailwind CSS v4
- [ ] تثبيت المكتبات: `react-router-dom`, `zustand`, `lucide-react`
- [ ] إعداد هيكل المجلدات (components, pages, stores, lib, types)
- [ ] إضافة RTL support (dir="rtl" + font عربي)
- [ ] إضافة `index.html` بـ meta tags أساسية

### Task 1.2: أنواع البيانات (Types)
- [ ] `Restaurant` — { id, name, slug, logo, whatsapp, currency, description }
- [ ] `Category` — { id, name, icon, sortOrder, parentId? }
- [ ] `MenuItem` — { id, categoryId, name, description, priceSYP, priceUSD, image, badge?, isAvailable, isFeatured }
- [ ] `CartItem` — { menuItem, quantity, notes, extras[] }
- [ ] `Offer` — { id, menuItemIds, discountPercent, startDate, endDate }

### Task 1.3: واجهة القائمة — التصنيفات
- [ ] شريط تصنيفات أفقي قابل للتمرير (horizontal scroll)
- [ ] تصنيف نشط مع تمييز بصري
- [ ] تصنيف "الكل" يعرض كلشي
- [ ] تأثير sticky عند التمرير

### Task 1.4: واجهة القائمة — بطاقات الأصناف
- [ ] شبكة بطاقات responsive (1 عمود موبايل، 2 تابلت، 3 ديسكتوب)
- [ ] كل بطاقة: صورة + اسم + وصف مختصر + السعر + زر إضافة
- [ ] شارة "مميز" أو "جديد" عند الحاجة
- [ ] حالة "غير متوفر" (مع تأثير grayed out)
- [ ] ضغط على البطاقة يفتح تفاصيل الصنف (modal/sheet)

### Task 1.5: واجهة القائمة — تفاصيل الصنف
- [ ] Modal/Sheet من الأسفل على الموبايل
- [ ] صورة كبيرة + اسم + وصف كامل
- [ ] قسم المحتويات
- [ ] قسم الإضافات (مع أسعارها)
- [ ] خانة ملاحظات
- [ ] أزرار +/- للكمية
- [ ] زر "أضف للسلة"

### Task 1.6: واجهة القائمة — سلة التسوق
- [ ] شريط سفلي ثابت يعرض عدد الأصناف + الإجمالي
- [ ] ضغط يفتح السلة (sheet من الأسفل)
- [ ] قائمة الأصناف مع كميات +/- وملاحظات
- [ ] حذف صنف
- [ ] الإجمالي الكلي
- [ ] زر "اطلب عبر واتساب"

### Task 1.7: واجهة القائمة — طلب واتساب
- [ ] دالة توليد رسالة واتساب منسقة
- [ ] الصيغة:
  ```
  🛒 طلب جديد من [اسم المطعم]
  ━━━━━━━━━━━
  1× برغر الشيف — 4,800 ل.س
  2× مارغريتا — 7,000 ل.س
  ━━━━━━━━━━━
  💰 الإجمالي: 11,800 ل.س
  ```
- [ ] فتح رابط `wa.me/{number}?text={encoded_message}`

### Task 1.8: بيانات تجريبية (Mock Data)
- [ ] مطعم تجريبي: "مطعم الذوق"
- [ ] 5 تصنيفات: بيتزا، برغر، سلطات، مشويات، مشروبات
- [ ] 3-5 أصناف لكل تصنيف
- [ ] عرضين خاصين
