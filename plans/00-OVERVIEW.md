# EZMenu MVP — نظام قوائم طعام رقمية

## 🎯 الهدف
بناء نظام قوائم طعام رقمية (MVP) يتيح للمطاعم إنشاء قائمة رقمية تفاعلية مع طلبات واتساب، لوحة تحكم، وإحصائيات.

## 🏗️ البنية التقنية

| المكون | التقنية |
|--------|---------|
| Frontend (زبون) | React 19 + TypeScript + Tailwind CSS + Vite |
| Admin Panel | React + Tailwind (نفس المشروع) |
| Backend API | Cloudflare Workers + Hono |
| قاعدة البيانات | Cloudflare D1 (SQLite) |
| التخزين (صور) | Cloudflare R2 |
| النشر | Cloudflare Pages |
| QR Code | مكتبة qrcode (JS) |
| الطلبات | واتساب عبر wa.me API |

## 📁 هيكل المشروع
```
ezmenu-mvp/
├── src/
│   ├── components/       # مكونات React مشتركة
│   ├── pages/
│   │   ├── menu/         # واجهة القائمة (الزبون)
│   │   └── admin/        # لوحة التحكم
│   ├── stores/           # Zustand state management
│   ├── lib/              # أدوات مساعدة
│   └── types/            # TypeScript types
├── plans/                # خطط التنفيذ
├── public/               # ملفات ثابتة
├── wrangler.toml         # Cloudflare Workers config
└── package.json
```

## 🧩 المكونات الأساسية (MVP)

### واجهة الزبون
1. صفحة القائمة مع التصنيفات
2. بطاقات الأصناف (صورة + اسم + سعر + وصف)
3. سلة التسوق
4. طلب عبر واتساب
5. QR Code للوصول السريع

### لوحة التحكم
1. تسجيل دخول
2. إدارة التصنيفات (CRUD)
3. إدارة الأصناف (CRUD + صور)
4. إعدادات المطعم (اسم + شعار + واتساب)
5. إحصائيات بسيطة

### Backend API
1. `/api/menu/{slug}` — جلب القائمة
2. `/api/admin/*` — إدارة كاملة
3. `/api/stats` — إحصائيات

## 📊 حدود MVP
- **مطعم واحد** لكل حساب (لا的多租户 في MVP)
- **طلب واتساب فقط** (لا يوجد نظام طلبات داخلي)
- **عملتين**: ل.س و $ (أسعار ثابتة)
- **لغة واحدة**: عربي (دعم إنجليزي لاحقاً)
- **بدون PWA** (لاحقاً)
