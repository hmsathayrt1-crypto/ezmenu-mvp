# Phase 3 — لوحة التحكم (Admin Panel)

## 🎯 الهدف
بناء لوحة تحكم كاملة لإدارة القائمة الرقمية: أصناف، تصنيفات، عروض، إعدادات، وإحصائيات.

## ✅ المهام

### Task 3.1: Layout الأساسي
- [ ] Sidebar مع روابط التنقل
- [ ] Top bar مع اسم المطعم + زر تسجيل خروج
- [ ] Responsive: sidebar مخفي على الموبايل (hamburger menu)
- [ ] حماية الـ routes (redirect للـ login لو مو مسجل)

### Task 3.2: صفحة تسجيل الدخول
- [ ] نموذج email + password
- [ ] حفظ token في localStorage
- [ ] Redirect للوحة التحكم عند النجاح
- [ ] رسالة خطأ واضحة

### Task 3.3: Dashboard (الرئيسية)
- [ ] بطاقات إحصائية: عدد الأصناف، عدد التصنيفات، زيارات اليوم، طلبات واتساب
- [ ] رسم بياني بسيط (زيارات آخر 7 أيام) — مكتبة `recharts`
- [ ] آخر العروض النشطة
- [ ] أصناف غير متوفرة (تنبيه)

### Task 3.4: إدارة التصنيفات
- [ ] جدول التصنيفات (اسم + أيقونة + ترتيب + حالة)
- [ ] إضافة تصنيف جديد (modal)
- [ ] تعديل تصناف
- [ ] حذف تصنيف (مع تأكيد)
- [ ] تغيير الترتيب (drag & drop أو أرقام)
- [ ] تفعيل/تعطيل

### Task 3.5: إدارة الأصناف
- [ ] جدول الأصناف مع فلتر بالتصنيف
- [ ] إضافة صنف جديد (صفحة كاملة):
  - اسم + وصف
  - تصنيف
  - سعر ل.س + سعر $
  - صورة (رفع)
  - إضافات (اختيار من قائمة)
  - شارة (مميز/جديد/حار)
  - متوفر/غير متوفر
- [ ] تعديل صنف
- [ ] حذف صنف (مع تأكيد)
- [ ] تفعيل/تعطيل
- [ ] تبديل "مميز" بضغطة واحدة

### Task 3.6: إدارة العروض
- [ ] قائمة العروض (عنوان + خصم + تواريخ + حالة)
- [ ] إضافة عرض جديد: عنوان + وصف + نسبة خصم + تواريخ + أصناف
- [ ] تعديل عرض
- [ ] حذف عرض
- [ ] تفعيل/تعطيل

### Task 3.7: إعدادات المطعم
- [ ] اسم المطعم
- [ ] وصف
- [ ] رقم واتساب
- [ ] شعار (رفع صورة)
- [ ] العملة الافتراضية
- [ ] توليد QR Code (تحميل PNG)
- [ ] معاينة القائمة (رابط)

### Task 3.8: الإحصائيات التفصيلية
- [ ] زيارات الصفحة (يومياً/أسبوعياً/شهرياً)
- [ ] طلبات واتساب (عدد + أكثر الأصناف طلباً)
- [ ] مسحوات QR (عدد)
- [ ] تصدير CSV (بسيط)

## 📦 المخرجات
- لوحة تحكم كاملة وشغالة
- CRUD لكل الكيانات
- إحصائيات تفاعلية
- توليد QR Code
